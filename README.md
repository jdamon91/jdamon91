## SentinelRN — Creator & Open Source Maintainer

**Application Trust Runtime for React Native**

**Stack:** TypeScript • React Native • Kotlin • Swift • Turborepo • AI Security

**Documentation:** https://jdamon91.github.io/SentinelRN/

**GitHub:** https://github.com/jdamon91/SentinelRN

**npm:** https://www.npmjs.com/package/@sentinelrn/native

SentinelRN is an open-source runtime integrity and AI security SDK for React Native that helps applications determine whether sensitive actions should be allowed based on runtime trust.

Instead of exposing isolated security checks, SentinelRN combines runtime integrity, AI prompt protection, structured threat scoring, and action-aware policy decisions into a unified developer experience.

### Engineering Focus

- Designed and built a production-ready monorepo architecture with TypeScript, Kotlin, Swift, and Turborepo.
- Developed a runtime trust engine that evaluates root, jailbreak, emulator, debugger, hooking, tampering, and AI security signals.
- Built AI PromptGuard with local detection for secrets, PII, and prompt injection before requests leave the device.
- Created a unified probabilistic risk scoring engine powering both runtime integrity and AI security.
- Focused on secure-by-default APIs, explainable threat reports, extensibility, and exceptional developer experience.
